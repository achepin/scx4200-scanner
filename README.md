# Samsung SCX-4200 Scanner for macOS

Небольшое локальное приложение для работы с МФУ **Samsung SCX-4200** на современных Mac.

Оно добавляет удобное сканирование с планшета и сохраняет результат в PDF, PNG или JPEG. После сканирования можно сравнить исходный вариант с версией, где внешний серый фон заменён белым, и сохранить подходящий вариант.

> Важно: это личный независимый проект, не официальный продукт Samsung или HP. Все файлы обрабатываются только на Mac, без облачной загрузки.

## Что умеет

- Сканировать с планшета SCX-4200 в цвете или оттенках серого.
- Работать в 150 dpi или 300 dpi.
- Сохранять сканы в PDF, PNG и JPEG.
- Немного уменьшать вертикальные полосы, которые иногда появляются на старом сканере.
- После каждого скана показывать два предпросмотра:
  - исходный скан;
  - вариант с белым внешним фоном.
- Добавлять Samsung SCX-4200 как принтер macOS.

## Совместимость

Готовый установщик из раздела Releases предназначен для Mac с **Apple Silicon**: M1, M2, M3 или M4, на macOS 14 или новее.

На Intel Mac исходники можно собрать локально, но готовый ZIP-релиз туда не подходит. Старый драйвер печати Samsung работает через Rosetta на Apple Silicon; установщик установит Rosetta при необходимости.

Сканирование построено на `sane-backends` и проверено с устройством, которое определяется так:

```text
SAMSUNG ORION multi-function peripheral
```

## Быстрая установка

1. Откройте [Releases](../../releases) и скачайте ZIP из последнего выпуска.
2. Распакуйте архив.
3. Подключите включённый SCX-4200 к Mac напрямую по USB.
4. Запустите `Install SCX-4200.command`.
5. Введите пароль администратора macOS, когда система попросит.
6. Дождитесь сообщения о завершении и откройте приложение `Сканировать SCX-4200` из папки «Программы».

Для установки нужен интернет. Если Homebrew ещё не установлен, установщик предложит поставить его с официального сайта, а затем установит `sane-backends` — компонент, через который работает сканер.

### Если macOS блокирует запуск

Это неподписанный личный проект. Нажмите на файл правой кнопкой мыши, выберите «Открыть», затем подтвердите запуск. Если этого недостаточно, в Терминале можно выполнить:

```zsh
xattr -dr com.apple.quarantine "/путь/к/папке/Installer"
```

## Как пользоваться

1. Положите документ или фотографию на стекло сканера.
2. В приложении выберите цвет, качество и формат файла.
3. Нажмите «Сканировать» и укажите место сохранения.
4. После сканирования сравните два изображения:
   - **Как есть** сохраняет натуральный скан со всем окружением.
   - **Белый фон** оставляет объект и заменяет пространство вокруг него белым.
5. Нажмите вариант, который нужно сохранить.

Белый фон не применяется автоматически: оригинал не перезаписывается, пока пользователь не подтвердит выбор.

## Сборка из исходников

Это нужно для разработки или для Intel Mac.

### Требования

- macOS 14 или новее;
- Xcode Command Line Tools: `xcode-select --install`;
- Homebrew;
- SANE backend:

```zsh
brew install sane-backends
```

### Сборка и запуск

```zsh
git clone https://github.com/achepin/scx4200-scanner.git
cd scx4200-scanner
./script/build_and_run.sh --verify
```

Готовое приложение появится в `dist/SCX4200Scanner.app`. Его можно перенести в папку `/Applications`.

## Ограничения и решение проблем

### 600 dpi

У SCX-4200 с современным SANE-драйвером полное цветное сканирование A4 в 600 dpi может завершаться ошибкой ввода-вывода. В интерфейсе поэтому доступны стабильные 150 и 300 dpi. Для документов и фотографий 300 dpi обычно достаточно.

### `scanimage: no SANE devices found`

1. Выключите МФУ кнопкой питания на 10 секунд.
2. Включите его и дождитесь полной загрузки.
3. Подключите кабель напрямую к Mac, без USB-хаба и переходника, если возможно.
4. Запустите сканирование ещё раз.

### `sane_read: Error during device I/O`

Обычно это означает, что сканер завис после неудачной попытки. Выключите МФУ на 10 секунд, включите и повторите скан на 300 dpi или 150 dpi.

### Принтер не появился после установки

Подключите и включите SCX-4200, затем запустите `Install SCX-4200.command` повторно. Установщик найдёт USB-устройство и создаст очередь `Samsung_SCX_4200_Series`.

## Разработка и обновления

После изменений проверьте приложение, затем сохраните результат в Git:

```zsh
git status
git add Sources script Installer README.md
git commit -m "Короткое описание изменения"
git push
```

Чтобы опубликовать новый готовый ZIP, соберите его через `script/build_and_run.sh`, обновите папку `Installer` и создайте новый GitHub Release.

## Лицензии и замечания

В папке `Installer/Samsung SCX-4200 driver` находится устаревший бинарный компонент драйвера Samsung, необходимый для печати. Его распространение и использование регулируются условиями Samsung/HP. Перед публичным распространением убедитесь, что это допустимо для вашего сценария.
