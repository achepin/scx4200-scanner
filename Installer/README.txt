Samsung SCX-4200: установка на другом Mac

Этот готовый комплект предназначен для Mac с Apple Silicon: M1, M2, M3 или M4.
Для Intel-Mac используйте исходники из репозитория GitHub и соберите приложение на самом Mac.

1. Подключите МФУ к Mac напрямую по USB и включите его.
2. Дважды нажмите «Install SCX-4200.command».
3. Введите пароль администратора Mac, когда его запросит система.
4. Дождитесь надписи «Готово».

Установщик добавляет:
- приложение «Сканировать SCX-4200»;
- компонент сканирования SANE;
- драйвер печати Samsung SCX-4200;
- очередь принтера Samsung_SCX_4200_Series.

Нужен интернет: если на Mac нет Homebrew, установщик поставит его с официального сайта,
а затем установит sane-backends для работы сканера.

Установщик также предлагает Rosetta, потому что старый драйвер
печати Samsung рассчитан на Intel. Без Rosetta сканирование будет работать, а печать может не заработать.
